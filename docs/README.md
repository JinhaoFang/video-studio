# 文档地图

| 文档 | 内容 |
|---|---|
| `../AGENTS.md` | 共同规则、角色、目录与归属（两个 agent 每次都会读） |
| `development.md` | 开发者手册：环境要求、`pnpm` 常用命令、`pnpm verify` 和 `pnpm qa` 验收子命令 |
| `roadmap.md` | 目标、已定的决策、下一步和待定，**新会话从这里看起**；进行中的工作看 GitHub 上打开的 spec |
| `workflow/README.md` | 制作工作流总图：每个阶段谁触发、用什么、产物在哪里 |
| `roles/design.md` | 设计负责人：自己做和派出去的判断标准、验收方法 |
| `roles/engineering.md` | 工程负责人：硬规则、可用技能、完成标准、汇报格式 |
| `agents/issue-tracker.md` | GitHub 工单的操作方法和本仓库的工单约定 |
| `agents/run-spec.md`、`agents/run-spec.json` | 执行技能的本仓库配置：脚本读取的值、其他本仓库特有的值、迁移方法 |
| `agents/triage-labels.md`、`agents/domain.md` | Matt 技能的标签表、术语文档布局 |
| `video/` | 视频知识：剧组各部门的决定（见 `workflow/README.md`「一期视频」的部门表）各有哪些选项、各是什么意思、适合什么情况、样片和出处；只写知识，不写步骤 |
| [video/motion.md](video/motion.md) | 动作部门⑭的知识：动画原则、节奏与间距、拖影、表演、鸟类运动与特效动画 |
| `research/table-videosop.md` | 对照：另一位作者的 Table-Video SOP，以及可以借用的做法 |
| `research/` 其余各份 | 一题一份的调研：`mg-styles-15.md` MG 风格拆解，`srt-whiteboard-animation.md` 白板技能实测，`noroi-iwai.md` 纯代码动画参照片的做法和小样对各条假设的验证结论，`elevenlabs-api.md` ElevenLabs 接口的实测与限制 |
| `reports/` | 每个视频 spec 完成后，设计负责人给用户的工作汇报：大多是 HTML 可视化页面，spec #1 是 Markdown |

开发流程（`run-spec`、`setup-run-spec`）的观察记录、规则判定标准、开局步骤和各版本汇报，2026-10-31 起在 `JinhaoFang/agent-workflow`。

`GLOSSARY.md` 和 `docs/adr/` 由 `/grill-with-docs` 在第一次定下术语或决策时自动生成。
