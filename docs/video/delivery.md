# 交付

对应「一期视频」清单的 ⑬ 封面、多版本、授权。只写知识：有哪些选项、各是什么意思、适合什么情况、样片和出处；制作步骤见 `docs/workflow/README.md`「一期视频」。条目格式见 [visual-style.md](visual-style.md)「条目格式」。平台的视频画幅与时长见 [planning.md](planning.md)「② 渠道与规格」。

出处核对日期：2026-11-09。这里的选用建议不代替平台条件或某份素材的具体许可；样片只作在线参考，不表示已取得搬运或商用权。

## 封面

### 成片中的代表画面

- **一句话**：用视频里真实出现的一帧，让人看出主体和内容。
- **适合**：人物、动作、物体本身就能说明看点的内容；单帧无法解释抽象主题时，可能需要另配标题或专门设计。
- **标志特征**：封面与正片内容一致，主体可辨，不靠一个正片没有的场面吸引点击。
- **关键技法**：表情、动作、结果或实物承担看点；标题与图片相互补充，承诺与视频一致。
- **出处**：[B 站投稿规范中的封面要求][bili-rules]（也可读[官方页面数据][bili-rules-data]）；[YouTube：缩略图与标题提示][youtube-title]、[自定义缩略图][youtube-thumbnail]。

### 主题图与短标题

- **一句话**：把主题、人物或产品与少量文字放在一张专门设计的图片里。
- **适合**：科普、教程、系列内容、产品介绍；需要让观众在列表中迅速看懂这一集讲什么。
- **标志特征**：文字简明可读，构图不过分复杂，主体与标题指向同一主题，内容没有误导。
- **关键技法**：清楚的主体、可读字体和适量信息承担识别；系列标记可以保持辨识度，但不能遮住这一集的具体主题。本条不另定颜色、字号或版式数值。
- **样片**：[YouTube 官方缩略图与标题示例页][youtube-title]（页面示例保留原权利，仅在线观看比较，不搬运）。
- **出处**：[YouTube：缩略图与标题提示][youtube-title]，包括准确性、简洁构图、可读字体和不同受众入口。

### 按展示位置区分的封面

- **一句话**：同一集在横向列表、竖向列表或其他入口里，封面可能以不同形状显示。
- **适合**：同时交付常规视频与短视频，或同一平台有多种展示入口的内容。
- **标志特征**：封面的尺寸要求与视频本身的尺寸要求分开；主体和必要文字能在相应入口辨认。
- **关键技法**：以 YouTube 官方电脑端说明为例，常规视频缩略图推荐 16:9、3840×2160，Shorts 推荐 9:16、2160×3840，JPG 或 PNG；上传大小上限随设备而异，电脑端该页写明 50MB，手机普通视频缩略图为 2MB。自定义权限有账号验证条件，且竖屏视频在部分入口可能显示自动生成的 4:5 图；这些数字不能直接当成 B 站、抖音或视频号要求。
- **出处**：[YouTube：自定义缩略图的尺寸、设备限制、权限和展示差异][youtube-thumbnail]。其他平台没有在本条得到核实的统一封面数值，不补写成通用规格。

## 多版本

### 横屏、竖屏与方形版

- **一句话**：同样的内容，用不同宽高比让主体和信息在各自屏幕里看得清。
- **适合**：同一期同时发布宽屏讲解与手机短内容；画面里有宽图表或并排人物时，画幅变化会影响能容纳什么。
- **标志特征**：宽高比与分辨率有明确区别；必要主体、图示和字幕在每个版本都完整可读。
- **关键技法**：裁切、重排和改用不同镜头是不同选项；横屏裁成竖屏会减少左右内容，不能假定同一构图一定适用。YouTube 播放器会按原比例调整，官方不建议直接给文件添加黑边。
- **出处**：[YouTube：播放器比例适配与分辨率][youtube-ratio]；裁切减少原画面可见范围是画幅变化的几何关系，重排则改变内容布局。各平台数字见 [planning.md](planning.md)「② 渠道与规格」。

### 完整版与独立短版

- **一句话**：完整版保留解释或故事，短版围绕一个能独立理解的看点。
- **适合**：一份内容有系统讲解与短内容两种用途；短版可能是独立知识点、产品解释或情节片段。
- **标志特征**：短版的对象、问题或事件有足够上下文，不因删掉前文而改变意思；长短版本各有明确主题。
- **关键技法**：分段能让学习内容围绕目标聚焦；产品解释片常把一个问题、产品价值与行动联系起来。合适时长取决于用途，平台的最长上传时长不是建议片长。
- **出处**：[Brame：学习目标、分段与简短视频][brame]；[Wistia：解释型产品视频的主题与常用时长][wistia]；[YouTube：Shorts 的分类条件][youtube-shorts]。

### 字幕版与可选字幕文件

- **一句话**：一种把字直接做进画面，另一种由播放器选择是否显示。
- **适合**：画面内字幕适合需要稳定显示文字的分发；可选字幕适合支持字幕轨道的平台、语言切换和字幕显示个性化。静音与听障观看都可能需要字幕。
- **标志特征**：画面内字幕不能由观众关闭；外挂字幕能由播放器显示或隐藏。无障碍字幕除了对白，还包含理解内容所必需的说话人、音乐或声音信息。
- **关键技法**：字幕时间与声音对应；无字幕画面配独立字幕文件可以支持多种语言，而固定压在画面里的文字会随视频一起显示。自动识别字幕仍可能有错。
- **出处**：[W3C：开放式与封闭式字幕、字幕内容][w3c-captions]；[YouTube：字幕文件、同步与自动字幕][youtube-captions]。

### 多语言旁白、字幕与口述影像

- **一句话**：语言版本帮助不同语言的人理解，口述影像帮助看不见重要画面的人获得信息。
- **适合**：跨语言传播，或关键信息只在图示、动作、场景变化中出现的内容。
- **标志特征**：译文、画面文字和旁白指向同一内容；普通旁白未讲出的必要视觉信息可以由口述补充，多语言配音与口述影像是不同用途。
- **关键技法**：平台支持多语言音轨时，同一条视频可带不同语言音轨；功能是否开放取决于账号。翻译后的音轨可能需要不同停顿和长度，不能只假定所有语言逐句等长。
- **出处**：[YouTube：多语言音轨及使用条件][youtube-language]；[W3C：音视频的字幕、描述与文字稿][w3c-media]。

## 授权

授权描述的是「谁允许在什么条件下使用什么」，不是文件能否下载。许可可能区分商业用途、改编、署名、投放媒体、客户和源文件转交；下面是常用选项与区别，不是一套制作步骤。

### 自有作品或另有书面许可

- **一句话**：内容由自己持有相应权利，或由有权许可的人明确允许用于这次成片。
- **适合**：原创图形、委托制作的配音与音乐、品牌提供的资料；委托制作和支付费用本身不能说明合同具体给了哪些使用权。
- **标志特征**：许可对象、允许用途、商业使用、修改、平台和期限能从权利依据或合同看出；交付成片与转交素材源文件是不同事项。
- **关键技法**：影片中涉及的视频、音乐、图像等各有权利依据；署名并不自动代替许可，权利人许可也不等于平台承诺免除一切版权争议。
- **出处**：[YouTube：取得使用受版权保护内容的许可][youtube-permission]；[Creative Commons FAQ：只有持有或有权许可的权利才能授权][cc-faq]。具体委托成果的归属依合同与适用法律，不在此作统一结论。

### 付费或免费的素材库许可

- **一句话**：素材库按具体条款允许使用，收费与否和允许怎样用是两回事。
- **适合**：购买或领取配乐、音效、图片、字体、视频素材的成片。
- **标志特征**：「免版税」不等于没有版权、无条件免费或能转卖源文件；标准、扩展等许可可能覆盖不同用途。
- **关键技法**：以 Adobe Stock 为例，图片与音频许可分别说明可用媒体和限制，音频普通许可与电视、广播等用途的许可范围不同；客户使用和素材原文件分发也受具体条款约束。这些条款不能自动套到其他素材库。字体同样有自己的许可，OFL 字体用于视频画面与分发字体软件也不是同一件事。
- **出处**：[Adobe Stock：图片、音频与客户使用许可][stock-license]；[SIL Open Font License FAQ：字体用于作品与字体软件分发][font-license]。

### Creative Commons 与 CC0

- **一句话**：CC 许可用几个条件说明作者允许怎样分享、修改；CC0 是尽可能放弃相关版权的工具。
- **适合**：素材明确标有具体 CC 版本或 CC0，并且本片用途符合其条件的情况。
- **标志特征**：BY 要署名；SA 要求分享的改编采用相同或兼容许可；NC 不授予商业用途；ND 不允许分享改编版。CC BY 和 CC BY-SA 允许商用，带 NC 的许可不能据此用于商业片；CC0 也不自动消除第三方肖像、隐私或商标等权利。
- **关键技法**：许可版本、作者、原始链接及修改说明是理解使用依据的重要信息；CC 将音乐与动态画面同步明确视为改编，因此 ND 音乐不能仅因「没有改旋律」就被当成可配视频的素材。
- **样片**：[《Spring》官方授权页][spring-license]（影片和项目内容为 CC BY 4.0，页面排除标志、商标及非本项目材料；本条仅作在线授权实例，不搬运）。
- **出处**：[Creative Commons：六种许可与 CC0][cc-licenses]、[FAQ：改编、音乐同步与其他权利][cc-faq]、[署名示例][cc-attribution]。

### 平台音频库与跨平台版本

- **一句话**：能在一个平台内选用的音乐，不自动说明可以带到所有平台或交给客户重复使用。
- **适合**：平台内配乐、广告投放，以及同一成片需要在多个平台发布的情况。
- **标志特征**：可用平台、署名条件和商业用途来自具体曲目的许可；「平台内能用」与「可自由下载再发布」有区别。
- **关键技法**：YouTube 音频库区分需要署名的 CC 曲目和不要求署名的曲目，官方帮助也明确其说明不替代站外使用的法律判断；Shorts 音乐库的使用时长与 Content ID 条件另有说明。跨平台版本的配乐依据必须覆盖实际发布用途。
- **出处**：[YouTube：音频库的署名与使用说明][youtube-audio]；[YouTube：三分钟 Shorts 的音乐和版权条件][youtube-shorts]。
