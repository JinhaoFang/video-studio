    仓库形态、目录、按句定时、技能冲突的处理，都是 agent 读完材料后提出的，用户没有改动。

结论

起作用的做法和付出的代价

起作用的

  • 人先备齐材料和工具，再开口
  • 先拆解参考，再讨论结构

    按句定时出自另一位作者说的"改配音就要重新对齐"。

  • 人叫停对齐，agent 以"结论、理由、要你决定的事"回应
  • 事实问题用实测回答
  • 放权以后报备
  • 纠正一次，改在一处，同步各处
  • 交接前检查新会话会读到什么
  • 留一份路线图作交接入口

付出的代价

  • 看图和讨论放在同一个会话

    27 张图让上下文在第一段就到 25 万。

  • 环境事实靠假设

    GPU、Codex 联网各让一段工作返工。

  • 照搬参考项目的约定
  • 命名定得晚

    临时名 my-video 后来要改名，会话记录分散在两个目录。

  • 用 root 建仓

    第一条 git 命令就失败。
