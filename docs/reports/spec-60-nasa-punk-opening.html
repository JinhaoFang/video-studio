    问题与处理

    遇到什么

    • #69 第二轮的调速指示错了设计负责人失误

      我让 Codex 用 ElevenLabs 的 speed 参数调快，但 eleven_v4 不支持，仓库里的 API 笔记早有记录。白花约 250 credits，#69 也因此多返工一轮。第三轮改成合成后用 rubberband 保音高变速，换倍率不用再花钱。

    • #69 返工 3 次

      第一轮暴露了两个读音问题：NASA 被逐个字母读，"后来"被读成 NASA。第二轮是上面那个调速失误。第三轮按统一倍率加速后，L008 吞字，单独放慢到 1.15 倍。每一轮都靠 pnpm qa voice 逐句复核错字率定位问题。

    • land 删 worktree 时连带删掉媒体

      #61 的临时配音只放在 worktree 里，合并后跟着 worktree 被删掉，只好重新生成。之后每次 land 前先把新媒体拷回主工作区，派发说明里也写明了这一点。

    • 并行镜头合到一起后，章节之间出现 1.2 秒黑场

      #66（第一章）和 #67（第二章）分开做，各自验收都对。合到一起才看到：第一章在 L007 说完就溶到黑，翻牌钟要到 L008 之后才出来。设计负责人对照参考，把它改成直接溶到翻牌钟。并行切开的镜头，衔接只能在合并后验收。

    • #67 跑了约 3.3 小时

      其他镜头工单 1 小时左右，#67 做了大量逐帧实测：无损逐列比对翻牌数字、换目标年份的变体渲染、整体后移时间轴的重渲染。结果可靠，但实测的量超过了工单的要求。

    • 合并冲突集中在同几个文件

      并行镜头都要改 Opening.tsx、tokens.ts 和本期 README，合并时每次都在这三个文件上冲突。都是"两边都保留"的简单冲突，按派发说明里"只加自己那一项"的约定解决。
