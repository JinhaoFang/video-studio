# NASA 朋克（设计风格小课 04）：视觉与声音系统

从参考视频抽帧、取色和音频测量整理，供重建时当"设计令牌"的起点。
参考文件是 B 站下载的 852×480 / 30fps，取色受压缩和调色影响，误差约 ±10（每通道）。
标记约定：**【事实】** 有原文出处；**【测】** 本仓库实测；**【推断】** 由画面推出。

## 3. 字体

【事实】简介：Archivo、Geist、Space Mono、思源黑体，均为 SIL OFL。下面的对应关系是【推断】：

| 字体 | 用在哪 | 例子 |
|---|---|---|
| Archivo（加宽、粗） | 大标题的拉丁字 | 结尾卡 `NASA-PUNK`、风格卡 `NASA 朋克` 的 NASA |
| Space Mono | 全大写小号标签、编号、读数，字距拉开 | `NASA LOGOTYPE · WORM · 1975`、`MISSION CLOCK · YEAR`、`STA 2140 / LOX TANK`、`DO NOT STEP`、出处行 |
| Geist | 拉丁正文，代替手册里的 Helvetica | 纸片上的手册引文 `technical precision. Elimination of…` |
| 思源黑体 | 全部中文：字幕、中文标签、风格卡 | `肉丸`、`不许重画`、`底材 / 结构 / …` |

四个都能免费取得（Google Fonts 有 Archivo、Geist、Space Mono；思源黑体可用 Noto Sans SC 代替）。

## 4. 字幕条

- 位置：底部居中，下边距约 6% 画高。
- 样式：半透明深色圆角矩形，白色思源黑体；**左端一小段竖向四色彩条**做身份标记。
- 切分：一条字幕 = 一句短旁白，一行放得下；句内停顿用全角空格代替标点（`这个标志　NASA 自己废过一次`）。
- 动效：两句之间字幕条收成只剩左端彩条，下一句再横向展开。【测】0:10、0:14 等帧只剩彩条

## 6. 运动语法

- **镜头**：照片上缓慢推拉平移；桌面场景里虚拟镜头推到某张纸片、再拉回总览；快速移动带运动模糊（1:24、4:02）。【推断】
- **元素进场**：线条"画出来"（角框、下划线、圈选）、标签逐字打出、纸片滑入带旋转、贴条"拍"上去、数字乱跳后停稳。
- **转场**：几乎全是软转场（短暗场溶解、纸片遮盖、镜头移动）。整片只检测到 2 处硬切（3:36、5:30）。【测】`select='gt(scene,0.25)'`
- **节奏**：画面变化跟着旁白的句子走，一句一个新信息点。

## 7. 声音

| 项目 | 结果 |
|---|---|
| 整片响度 | -16.0 LUFS（integrated），LRA 2.9 LU【测】 |
| 对照：桌子 SOP 视频 | -15.0 LUFS，LRA 3.4 LU【测】 |
| 静音段 | 低于 -45 dB 且超过 0.4 秒的只有 1 处，BGM 全程铺着【测】 |
| 频谱 | 旁白下面是一层持续的低频铺底（约 100 Hz 以下）；有短促的音调型提示音，如 14～15 秒翻牌钟处约 2.3 kHz 的嘀嗒【测】 |
| 配音 | MiniMax `speech-2.8-hd`，逐段合成【事实】 |
| 旁白节奏 | 191 句，累计 284 秒（占全片 80%），平均每句 1.5 秒，约 300 字 / 分钟。约一半的切句处是连读（间隔小于 0.15 秒，同一口气里按逗号切成两条字幕），其余停顿大多在 0.3～0.8 秒【测】`transcript.md` |
| 配乐与音效 | 程序合成【事实】 |

B 站的 AAC 把 13 kHz 以上都切掉了，高频细节没法判断。
