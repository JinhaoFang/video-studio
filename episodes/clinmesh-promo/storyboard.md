# ClinMesh 宣传视频镜头剧本（精修版 · 局部裁剪 × 多病种智能体矩阵）

- **实测总时长**：`97.03` 秒（`2911` 帧，`1920×1080 @ 30fps`），配音为浑厚沉稳普通话男中低音（ElevenLabs `Brian` × `eleven_v4`，等高 `1.10x` 变速）。
- **构图减负与实机裁剪策略**：吸收 ShipScenes、Motion Reference（_Harvey Legal Work Orchestration_ / _Floe Health_ / _Devin Oncall_）与 Inspo.zone 标杆经验，实机画面采取 **「重点区域高清裁剪切片 + `PageCam` 布局级 CSS `zoom` 聚焦 + 原生语义 Token 卡片」**；正片 `S02`–`S07` 全面去除左上角英文眉标及卡片内冗余英文状态码（如底板协议串、签署状态英文与审计编号），`B01`–`B03` 呼吸字卡去除英文副标题，仅在终章收尾保留双语结语，把观众注意力集中到核心临床流程与中文标题。
- **动效与声音准则（`video-shotcraft` × `sound`）**：一镜一主运动语法；开场与片尾 `ClinMesh` 品牌字标落定后 **真静止 `>= 1.0s`（开场 `2.53s`，片尾 `1.83s`）**，批量元素归位后 **静止 `>= 0.5s`**；禁用手持随机抖动与群发泛光；人工审阅确认阶段严格遵守临床 UI 合同保持静态无 AI 发光；SFX 全程采用真实物理拟音与电影重音，按相对句子起点钉帧并启用双偏移同步补偿。
- **命名与合规红线**：严禁出现内部工程代号；`S07` 自研病理切片识别模型采用绿色已完成状态框标注 `自研多模态模型`，`SLOT 02`–`04` 多病种智能体采用纯合成深色三维生物医学示意图像平衡视重，开发与自动化抽帧验收阶段不读取真实医学影像或病理切片像素。
