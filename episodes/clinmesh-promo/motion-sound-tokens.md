## 2. 动效性格参数与镜头卡映射（`video-shotcraft`）

### 2.1 全局时间与缓动常量（`30fps`）

- **常规面板与相机推拉**：主时长 `22–28f`，缓动 `EASE.snappy = bezier(0.16, 1, 0.3, 1)`（干脆起步、柔和落定），全片禁用 `handheld` 随机相机抖动。
- **物理咬合与发布会飞入（特例过冲）**：
  - `S07` 病理准星锁定（`reticle-lock-on`）：外扩 `2.2x → 0.94x → 1.02x → 1.0x` 超调咬合。
  - `S08` 终章六卡四方飞入（`outro-group-photo-launch`）：`EASE.overshoot = bezier(0.34, 1.36, 0.44, 1)` 配合方向性 `SpeedBlur`，并在品牌压印后经 `EASE.swift` 向四周错峰外扩虚化蒸发。
- **强制呼吸帧预算**：
  - 开场 `S01` 与终章 `S08` 的 `ClinMesh` 字标落定后：**真静止 `>= 30f`（`S01 = 2.53s`，`S08 = 1.83s / 55f`）**，相机完全锁死无尾漂。
  - `S03` 候选行嵌入、`S07` 四格多病种智能体矩阵展开收尾：**静止 `>= 15f`（`0.5s`）**。
  - `B01`–`B03` 呼吸字卡：固定 `52f`（`1.73s`），嵌在 `L005`、`L008`、`L010` 的 `1.90s` 句后停顿内（分别显示 `01 无感伴随智能 · 静默运转`、`02 溯源质控 · 人工把关`、`03 多病种智能体 · 即插即用`）。
- **高清栅格化铁律**：`PageCam` 推进特写统一采用 **布局级 CSS `zoom`** 配合高分切片向下采样，禁止对 `1920` 布局层直接做大倍率 `transform: scale(>1)` 导致文字发糊。

## 3. 音效钉帧与音画对齐公式（`sfx-schedule.ts`）

1. **按句子相对帧号声明中央 SFX 注册表**：所有钉点基于 `sentenceFrame(timeline, id, offset)` 计算，严禁散落硬编码绝对帧号；重配任意句子或调整停顿时全表自动跟随平移。
2. **实测双项偏移统一扣除**：
   ```ts
   export const OUTPUT_AUDIO_OFFSET_F = 0.21;
   export const MEASURED_PEAK_F: Record<string, number> = {
     "fs-71852.mp3": 13.05,
     "fs-464302.mp3": 34.05,
     "fs-444431.mp3": 14.85,
     "fs-331656.mp3": 0,
     "fs-520684.mp3": 25.65,
     "fs-629979.mp3": 5.25,
     "fs-815493.mp3": 4.95,
     "fs-278205.mp3": 1.05,
     "fs-685256.mp3": 82.35,
     "fs-177242.mp3": 55.35,
     "fs-671375.mp3": 1.05,
     "fs-562196.mp3": 0.45,
   };
   export const sfxFrom = (targetPeakF: number, src: string): number =>
     Math.max(
       0,
       Math.round(
         targetPeakF - (MEASURED_PEAK_F[src] ?? 0) - OUTPUT_AUDIO_OFFSET_F,
       ),
     );
   ```
3. **防机枪感与长样本裁剪**：
   - `S03` 键盘打字声（`fs-331656.mp3`）显式挂载 `durationInFrames: 72` 并做尾端 `8f` 淡出，动作停则声音停。
   - `S03` 候选行批量 `row-embed` 靠底边 `2px` 蓝缝闪烁提供视觉节奏，不逐行叠加提示音。
   - `S07` 病理切片两个 ROI 准星依次咬合时，交替使用 `fs-520684` 与 `fs-629979`，音量由 `0.36` 递减至 `0.25`。
4. **稳态无闪避混音与自然尾音收束（No-Ducking & Natural Tail Decay）**：
   - **取消旁白自动闪避（No Ducking）与乐段均衡**：配乐床 `Clinical AI Underscore.wav` 严格禁用句间或呼吸字卡处的自动闪避，仅按乐曲四段编曲结构做长跨度平滑平衡（`BGM_STEADY_VOLUME = 0.46` 配合 `bgmScoreBalance`），做到配乐推动力清晰稳健且不掩蔽旁白；成片响度校准使用线性增益，不引入动态压限抽吸。
   - **配乐首尾连续曲线过渡**：配乐在开场前 `36f`（`1.20s`）余弦渐入，并在片尾 `S08` 最后 `60f`（`2.00s`）连续余弦渐隐至静音。
   - **旁白与片尾音效自然衰减**：`L001`–`L014` 逐句配音不设截断；片尾 `L014` 句后保留 `1.10s`（全片 `01:37.03` / `2911f` 收束），确保 `fs-562196` 完整释放自然尾音、`fs-177242` 经 `183f` 包络与 `48f` 平滑淡出自然归零（由 `sfx-schedule.test.ts` 自动化契约守护）。
