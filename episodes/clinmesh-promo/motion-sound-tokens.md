# ClinMesh 宣传片动效与声音约定

本期做画面和声音时遵守的约定。数值只存在代码里：颜色、圆角、字幕、颗粒暗角和配乐音量在 `tokens.ts`，缓动在 `motion-utils.ts` 的 `EASE`，音效钉帧和峰值补偿在 `sfx-schedule.ts`，浅色工作台在 `light-stage.tsx`。本文不复制这些数值。

约定来自三处：ClinMesh 产品的界面样式（产品仓库的 `packages/ui/src/styles.css`，不在本仓库）、外部技能 `video-shotcraft` 的镜头卡和审美准则，以及 `sound` 的拟音选型方法。两个技能见 [README](README.md)「参考与外部技能」。

## 画面

- **两种舞台**：S01、S02、S07、S08 用深色舞台，底色和面板色对齐产品的深色主题，强调色只用一个（`stageAccent`）。S03–S06 用浅色工作台展示真实产品界面，这一段关掉颗粒暗角层 `PromoFinish`。
- **产品卡片**用产品原生的样式：控件 6px、卡片 8px 圆角，数字用 `tabular-nums` 防止跳动。医生人工核准的界面不加发光特效。`tokens.ts` 里的 `clinmeshGlowShadow` 是旧版助手草稿卡用的，最终版没有用到。
- **文字减负**：标题和字幕用中文。正片不放左上角英文眉标，呼吸字卡不放英文副标题；英文副标题只出现在 S08 结尾。界面里的技术标签（如 S07 的 `SLOT`、`ROI`）和素材署名可以用英文。
- **清晰度**：推近用布局级 CSS `zoom` 配合 2 倍截图下采样，不对 1920 宽的布局层做大倍率 `transform: scale`，避免文字发糊。
- **运动**：一个镜头只有一个主运动；同一画面换景别用同一台相机连续推拉（仓库规则见 `docs/roles/design.md`「镜头运动」）。不用手持抖动，不用成批的扫光。品牌主标落定后至少静止 1 秒，成批元素落定后至少静止 0.5 秒。
- **超调**只用在两处物理咬合：S07 准星锁定和 S08 卡片飞入（`EASE.overshoot`），其余用 `EASE.snappy`。

## 声音

- **钉帧**：每个音效声明目标峰值所在的帧，用 `sentenceFrame` 或镜头起点加偏移表示，不写绝对帧号。`sfxFrom` 减去样本自身的起音到峰值时间（`sfx/audio-manifest.json` 实测）和输出编码的偏移，让峰值对准画面动作。
- **防机枪感**：成批出现的元素不逐个配音效；长样本按动作裁短并在末尾淡出；连续两次相同动作换样本、递减音量。
- **选型**：只用真实录音的 CC0 拟音和电影音效，不用游戏风格的合成提示音。
- **配乐**：不做旁白闪避，按乐曲段落做长跨度平衡，首尾余弦渐入、渐出。可以去掉配乐，渲染只保留旁白和音效的版本（`data/props-nobgm.json`）。
- **片尾**：`L014` 后留 1.10 秒，终章音效的尾音和渐出要在片尾前结束。有媒体时由 `sfx-schedule.test.ts` 检查，没有媒体时跳过。
- **成片响度**：-16 LUFS ±1 LU，真峰值 ≤ -1 dBTP，用 `pnpm qa loudness` 验收。
