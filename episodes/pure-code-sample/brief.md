# 简报

**一句话**：夏日傍晚雷阵雨刚停，檐下晾衣竹竿上一只湿透的小麻雀，被最后一滴雨打醒，抖干羽毛，朝夕光飞走。

两个镜头，13 秒，没有对白和字幕，只有器乐和音效。时间表、色彩剧本和技术规则见 [本期约定](contract.md)，逐镜的画面和运镜见 [镜头剧本](storyboard.md)。

## 观众此刻的感受

| 镜头 | 感受 | 节拍 | 声音 |
|---|---|---|---|
| S1 雨停 | 安静，雨后的凉意慢慢被暖光推开；看到小麻雀时心软；水珠打中它时一个小小的"啊" | 雨渐稀 → 云缝透光、光扫过稻田 → 推近竹竿上的麻雀 → 檐口最后一滴落在它头顶 | 雨的尾声和檐下滴水；光到时进来一个小动机的头两个音；最后一滴有清楚的落点 |
| S2 抖水起飞 | 被逗笑（抖水），被它抬头看光的那一下打动，最后跟着它飞起来的轻快，留一点余韵 | 一缩 → 抖水 → 蓬成一团停住 → 抬头看光 → 压身 → 起飞 → 空竹竿弹动、夕光 | 抖羽和甩水；蓬起后故意留一拍静默；起飞时动机上扬，振翅；竹竿弹响；最后一个音留在空竹竿上 |

## 品质标准

验收时看画面就能逐条核对。

- **角色**：麻雀的轮廓一眼认得出；平涂加一层硬边阴影，可以有轮廓光，没有柔和渐变；线条暖深色，有粗细变化，两端收尖，转折处像抬笔那样断开；不同角度、不同表情下是同一只鸟。
- **背景**：像水粉画。眯眼能看到 3–5 块清楚的大明暗；树篱、稻株、云团、木纹每一个都看得出是单独画的；笔触顺着形体走；有安静、没画满的区域；远近之间有空气。
- **光**：雨色是冷的蓝灰，夕光是暖金；阴影带颜色（紫、蓝、青）；湿的木头、竹竿、叶子上有窄而亮的高光；暖光照到哪里，哪里的底图和角色一起变暖。
- **动作**：角色一拍二，抖水和起飞最快的几帧一拍一并有拖影；关键姿势停得住；有预备和跟随；相机每帧都在慢慢动。
- **摄影**：有柔焦和高光光晕，四角有轻微色差和暗角；颗粒在暗部明显、亮部干净。

## 绝不能像

- **网页动画**：平滑的软件缓动、回弹缓动、整层平移、一直上下浮动、木偶式绕关节旋转。
- **矢量图**：等宽描边、完美的圆和椭圆、直尺画的线、简单渐变、几何形拼贴。
- **3D**：塑料质感、角色上的柔和明暗、计算机式的完美透视。
- **AI 画**：造型在帧之间漂移、细节融化、闪烁。
- **粒子系统**：均匀分布、一样大小、一样速度的雨丝和水珠。
- **复制粘贴**：两片叶子、两株稻、两颗水珠一模一样。
- **业余**：浑浊的颜色、灰黑的阴影、纯黑、像没画完的空白、合成噪声的条纹、HDR 光晕。
